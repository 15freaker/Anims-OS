# Anims-OS

* this is small basic os which is totally web based

# Screenshot 

![screenshot](image.png)

# features 

* it has a calender
* it has a mini music player
* it haa weather telling box
* it has a basic notes app
* it has wiki pedia browser
* it has a cat image in center
* it has dark theme 
* you can drag any window
* you can see time
* you can see date
* it has basic calculator

# what i used to make this project 

* i used online present images address for apps logo and desktop cat image 
* i used royality free music for mini music player
* fuctions i used in js for calender are 
  1. new Date()
  2. getFullYear()
  3. getMonth()
  4. getDay()
  5. getDate()
* i used Browser Geolocation API to capture coordinates
* i used Open-Meteo REST API to retrieve live forecast data
